在现实环境里,因为服务拆分的问题,有可能出现多个数据源,并不像之前一个数据源就能搞定.

所以在 spring 里面学会使用多数据源配置很重要,本文档使用SpringBoot+Mybatis-plus,请知悉.

在 spring 配置多数据源主要有两种方式

  • 扫描指定的 package
  • 使用 aop 切面
