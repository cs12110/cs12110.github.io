1. 安装 docsify

该章节描述 docsify 的安装.

1.1 安装 nodejs

因为 docsify 依赖 nodejs,我们先安装 nodejs.

下载 nodejs 压缩包,解压并且设置环境变量即可.

设置环境变量

使用source /etc/profile重新加载环境变量即可.

1.2 安装 docsify

这个在网上都是使用npm i docsify-cli -g,但是出现了异常.

解决方法是进入到 npm 所在位置进行安装,如lib/node_modules/.

等待安装完毕即可.
