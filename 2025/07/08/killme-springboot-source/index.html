准备环境

springboot 加载配置监听器:org.springframework.boot.context.config.ConfigFileApplicationListener

spring 加载核心: org.springframework.context.support.AbstractApplicationContext#refresh,参考 link

从上面的:ConfigurableListableBeanFactory beanFactory = obtainFreshBeanFactory();

初始化 bean:org.springframework.context.support.AbstractRefreshableApplicationContext#refreshBeanFactory

注解解释注入 ioc:org.springframework.context.support.AbstractApplicationContext#finishBeanFactoryInitialization 参考 link

org.springframework.context.annotation.AnnotationBeanNameGenerator#buildDefaultBeanName(org.springframework.beans.factory.config.BeanDefinition)

我一直很好奇,springboot 是怎么把各种Controller,Service注册进去 ioc 里面的,跟踪代码可以看到走到了这里: org.springframework.context.support.AbstractApplicationContext#invokeBeanFactoryPostProcessors这里实现了黑魔法.

这一块最重要:org.springframework.context.support.PostProcessorRegistrationDelegate#invokeBeanFactoryPostProcessors(org.springframework.beans.factory.config.ConfigurableListableBeanFactory, java.util.List<org.springframework.beans.factory.config.BeanFactoryPostProcessor>)
