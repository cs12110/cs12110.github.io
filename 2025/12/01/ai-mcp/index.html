3. 参考资料

3.1 uv 常用命令

命令 举例 说明
uv add uv add requests 添加一个包到项目依赖
uv remove uv remove requests 从项目依赖中移除一个包
uv sync uv sync 同步虚拟环境，安装所有依赖
uv run uv run python app.py 在虚拟环境中运行命令
uv lock uv lock 生成或更新锁文件
uv tree uv tree 显示依赖树
uv init uv init myproject 创建一个新的 Python 项目
uv shell uv shell 激活虚拟环境的 shell
uv python uv python 启动虚拟环境中的 Python 解释器
uv version uv version 显示 uv 版本信息

uv venv 命令

命令 举例 说明
uv venv uv venv 在当前目录创建默认虚拟环境
uv venv uv venv .venv 创建名为 .venv 的虚拟环境
uv venv uv venv --python 3.11 指定 Python 版本创建环境
uv venv uv venv --prompt "myproject" 创建带自定义提示符的环境
uv venv uv venv --seed 在环境中预装 pip 和 setuptools
uv venv uv venv --no-seed 创建空环境，不预装任何包
uv venv uv venv --system-site-packages 允许访问系统站点包
激活环境 source .venv/bin/activate 激活虚拟环境 (Linux/Mac)
激活环境 .venv\Scripts\activate 激活虚拟环境 (Windows)
退出环境 deactivate 退出当前虚拟环境
删除环境 rm -rf .venv 删除虚拟环境 (Linux/Mac)
删除环境 rmdir /s .venv 删除虚拟环境 (Windows)

3.2 mcp 参数格式

类型 格式 说明 示例
成功响应 {"result": "success", "data": {...}} 操作成功返回格式 {"result": "success", "data": {"message": "Done"}}
错误响应 {"result": "error", "error": "...", "code": "..."} 操作失败返回格式 {"result": "error", "error": "Invalid input", "code": "INVALID_INPUT"}
工具调用 {"tools": [{...}]} 返回可用工具列表 {"tools": [{"name": "search", "description": "Search web"}]}
资源列表 {"resources": [{...}]} 返回可用资源列表 {"resources": [{"uri": "file:///data", "name": "Data"}]}
数据内容 {"contents": [{...}]} 返回内容数据 {"contents": [{"type": "text", "text": "Hello"}]}
分页响应 {"data": [...], "next_cursor": "..."} 分页数据返回格式 {"data": [...], "next_cursor": "page2"}
错误码 说明
INVALID_REQUEST 请求格式错误
UNAUTHORIZED 未授权访问
RESOURCE_NOT_FOUND 资源未找到
INTERNAL_ERROR 服务器内部错误
RATE_LIMITED 请求频率限制
