Redis 数据导入优化

在 Java 使用 jedis 操作 redis 的单个节点时候,可以使用 jedis 的 pipelined 来操作数据,类似于 jdbc 的批量处理来加快速度.

但是由于 JedisCluster 连接 redis 集群的时候,因为没有提供 pipelined,所以在某些导入大量数据的时候,耗时很尴尬.

那么,我们来看看 redis 集群该怎么优化数据导入. :”}
